# ADR-0005: WMS에서 IMS로 이관 없이 분리

## 상태

Accepted (2026-10-05)

## 배경 (Context)

재고 관련 데이터와 로직(재고, Lot, 재고 이력, 점유, 상품)이 현재 WMS에 있다. IMS를 새로 만들면 이를 언제 어떻게 옮길지 정해야 한다.

## 결정 (Decision)

데이터 이관 없이 분리한다. IMS를 구현한 뒤 WMS를 IMS 호출 구조로 바꾸고, 개발 DB는 시더로 다시 채운다.
WMS 쪽 변경은 WMS 프로젝트에서 처리하며 이 레포의 범위가 아니다.

## 결과 (Consequences)

- 전제: WMS에 보존해야 할 운영 데이터가 없다(개발 단계). 운영 데이터가 생긴 뒤에 전환하게 되면 이 결정을 다시 검토해야 한다.
- 얻는 것: 이관과 이중 쓰기 비용이 없다. WMS의 상품 ID를 그대로 승계할 수 있다([erd.md](../erd.md)의 ERD-01).
