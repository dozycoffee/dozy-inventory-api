# ADR-0004: 마스터 데이터 소유

## 상태

Accepted (2026-10-05)

## 배경 (Context)

상품은 WMS(Zone 매핑), IMS(재고), OMS·가맹점(판매·발주)이 모두 쓰는데 소유 서비스가 정해지지 않았다. 현재 상품·창고 마스터는 WMS에 있다.
IMS의 재고 행은 `상품 ID × 창고 ID × Lot × 품질 상태`라 상품과 창고를 ID로 가리키기만 하면 된다.

## 결정 (Decision)

- 창고 마스터는 WMS가 소유하고 IMS는 창고 ID만 참조한다.
- 상품 마스터는 IMS가 소유한다. 상품 자체 정보(코드, 이름, 단위, 카테고리, 유통기한 관리 여부 등)만이며, 카테고리 → Zone 매핑은 WMS에 남긴다(IMS는 Zone을 모른다는 원칙 유지).
- WMS는 IMS가 발행하는 상품 이벤트로 로컬 사본을 유지한다. IMS가 장애여도 WMS가 입고·출고를 진행할 수 있어야 하기 때문이다.

## 결과 (Consequences)

- 얻는 것: 상품 소유가 불명확한 상태에서 일단 한 곳에 두고 진행한다.
- 감수하는 것: IMS의 범위가 재고 외 상품 마스터까지 넓어진다. 나중에 별도 마스터 서비스로 옮기면 한 번 더 이전해야 한다. (검토한 대안인 "WMS에 그대로 두고 IMS는 ID만 신뢰"가 당시 추천안이었으나 선택하지 않았다.)
- 나중에 분리하기 위한 조건: (1) 다른 서비스는 상품을 ID로만 참조한다. (2) 상품 ID는 어디로 옮겨도 바뀌지 않는 값이다. (3) 다른 서비스의 DB가 상품 테이블을 직접 JOIN하지 않는다.
