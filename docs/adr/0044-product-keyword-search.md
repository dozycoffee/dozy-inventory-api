# ADR-0044: 상품 목록 키워드 검색

## 상태

Accepted (2026-10-15). 상품 목록 조회(ADR-0004의 상품 마스터 API)에 검색어 조건을 더한다. 기존 조건과 응답은 바뀌지 않는다.

## 배경 (Context)

상품 목록의 코드 조건(`code`)은 정확히 일치하는 상품만 찾는다. 어드민 콘솔의 상품 선택(재고 현황 필터)과 원자재 화면의 검색은 이름이나 코드의 일부로 찾아야 하는데, 지금은 상품 목록을 처음 몇 페이지(최대 500건)까지 모두 받아 콘솔에서 거른다. 상품이 그 이상이 되면 뒤의 상품은 찾을 수 없다.

## 결정 (Decision)

1. **`GET /api/v1/products`에 선택 조건 `keyword`를 더한다.** 앞뒤 공백을 없앤 글자가 **상품 코드나 상품 이름에 들어 있는** 상품을 찾는다(부분 일치). 공백뿐이거나 비어 있으면 조건을 적용하지 않는다.
2. **대소문자와 악센트는 컬럼 정렬 규칙(`utf8mb4_0900_ai_ci`)대로 구분하지 않는다.** 코드를 대문자로 바꾸는 `code`와 달리 입력을 바꾸지 않는다.
3. **`%`, `_`, `\`는 와일드카드가 아니라 글자 그대로 일치한다.** 검색어에서 이 글자 앞에 `\`를 붙여 `LIKE` 패턴을 만든다. 검색어는 이름 붙은 파라미터로만 넣는다.
4. **다른 조건과는 AND로 묶는다**(`code`, `category`, `status`). 코드 또는 이름 중 한쪽만 일치해도 키워드 조건을 만족하고, 이 OR는 하나의 묶음으로 다른 조건과 AND된다.
5. **정렬과 페이지는 그대로다**: `product_id` 오름차순, `page`(0부터), `size`(1~100). 일치 정도(관련도) 정렬은 하지 않는다.
6. **검색어는 앞뒤 공백을 뺀 길이가 100자까지**이고 넘으면 400(`INV_INVALID_PRODUCT_KEYWORD`)이다.
7. **권한은 목록과 같다**(`PRODUCT_READ` 호출자). 상품 쓰기 권한과 무관한 읽기 조건이다.

## 결과 (Consequences)

- 얻는 것: 콘솔이 상품을 전부 받지 않고 입력한 만큼 서버에서 찾으므로 상품 수에 제한이 없다. 코드와 이름을 한 입력으로 찾는다.
- 감수하는 것: 앞에 `%`가 붙는 `LIKE`라 인덱스를 쓰지 못하고 상품 테이블을 훑는다. 상품 마스터가 수천 건 이하인 동안은 문제가 없고, 훨씬 커지면 전문 검색(FULLTEXT)이나 접두 일치로 바꾼다. 관련도 정렬이 없어 흔한 글자는 많은 결과가 `product_id` 순으로 나온다.
